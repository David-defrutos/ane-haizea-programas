become → became → become

⚡ Tres trampas típicas

go → went → gone: cada forma es distinta.
lay → laid → laid: poner, colocar.
get → got → got: esta es la forma que aparece en tu hoja.

En la hoja aparecen hanged/hung. Para «colgar/eseki», lo habitual es hung; hanged se usa normalmente para «ahorcar». Aquí se aceptan las dos formas de la hoja.

El truco que más ayuda

Mira un verbo, tapa V2 y V3, dilo de memoria y comprueba. Si falla, vuelve a él después de otros verbos. Leerlo muchas veces ayuda menos que intentar recordarlo.
