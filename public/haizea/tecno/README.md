# Tecno · Energia

Quiz y 52 flashcards en euskera y castellano, a partir de cinco páginas de apuntes y tres imágenes de ejercicios. Seis temas y un filtro «Repaso del examen» de 26 tarjetas, rondas de hasta 10 preguntas o todas, repaso de fallos y tarjetas pendientes. Cambiar tema o modo inicia una ronda nueva; cambiar idioma mantiene la ronda.

Las fotos originales permanecen fuera del repositorio. Se han aclarado definiciones: la electricidad no es una fuente primaria; el contador mide energía y la línea general de alimentación une la caja de protección con la centralización de contadores. Se añaden tres ejercicios sencillos de Ohm. Los valores de tensión del cuaderno se citan como referencias de clase, sin convertirlos en reglas universales.

El progreso se guarda por el identificador devuelto por `/api/me`, en este navegador. Sin sesión válida se puede practicar, pero no se guarda progreso. No utiliza el ranking de Verb Quest.

## Publicación

Ruta: `/haizea/tecno/`. Los archivos web se sirven con el alojamiento protegido del proyecto. Subir a GitHub publica el código; para actualizar el sitio alojado hace falta ejecutar el despliegue de Cloudflare documentado en el README principal. No activar GitHub Pages para el portal protegido.

## Ejercicios añadidos

16 tarjetas nuevas: cuatro de verdadero/falso, tres huecos, la explicación de las pérdidas a baja tensión, ubicación de contadores, orden del recorrido hasta la vivienda y seis identificaciones en el esquema propio instalacion.svg. El dibujo es una adaptación esquemática, no una copia de las fotos. Se mantienen los identificadores y el almacenamiento de las 36 tarjetas anteriores.

La reducción de pérdidas al elevar la tensión se explica para la misma potencia transportada. La comparación de grosor de cables supone iguales material, longitud e intensidad. El filtro de examen reúne ejercicios de las nuevas hojas y conceptos previos relacionados; no asegura el contenido del examen.
